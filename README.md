# 📚 Book Store Web Application

A responsive bookstore web application built with React, Redux Toolkit, and React Router. Users can explore books, filter them by category, view book details, and manage their shopping cart.

## ✨ Features

- Browse books from a database.
- Filter books by category.
- Paginated book listings.
- View detailed information for each book.
- Add books to the shopping cart.
- Manage cart items and quantities.
- Responsive user interface.

## 🛠️ Technologies Used

- React.js
- JavaScript (ES6+)
- Redux Toolkit
- React Redux
- React Router
- CSS3
- Bootstrap
- JSON Server
- REST API

## 🗂️ Data Source

This project uses JSON Server as a mock REST API to manage and retrieve book data.

## 📦 Installation & Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/mohammedsaeed090909-ship-it/bookStoreReactProject.git
   ```

2. Navigate to the project directory:

   ```bash
   cd bookStoreReactProject
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the JSON Server:

   ```bash
   npx json-server --watch db.json --port 9000
   ```

5. Start the React application in a separate terminal:

   ```bash
   npm start
   ```
